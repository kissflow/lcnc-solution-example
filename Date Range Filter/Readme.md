📅 Date Range Filter – Kissflow Custom Component
The Date Range Filter custom component provides an intuitive interface for selecting a date range using "From" and "To" fields. It is designed for seamless integration within Kissflow Apps and Pages, allowing users to filter data, reports, or processes by specific date intervals.

📦 File Included
Daterange.zip
 Contains the complete custom component package with the required index.html.

🛠 How to Use in Kissflow
1. Upload the Component
-  Navigate to your Kissflow App.
-  Go to the Custom Components section.
-  Upload Daterange.zip directly.

2. Create Required VariablesCreate the Required Variables
-  Create a variable named from of type Date/Time – stores the selected "From" date.
-  Create a variable named to of type Date/Time – stores the selected "To" date.
-  Note: Variable names are case-sensitive. Use exactly from and to.

3. Add the Component to Your Page
-  Insert the uploaded Date Range Filter component into any page in your Kissflow app.
-  Resize or align as needed.

✅ Functionality Highlights
-  Date Range Selection: Pick both From and To dates.
-  Validation: To Date cannot be earlier than From Date.
-  Clear Button: Removes selected values and resets the associated Kissflow variables.

📊 Ideal Use Cases
-  Filtering reports by custom date range
-  Dashboards with time-based data slicing
-  Workflow or audit trail filtering

You’re all set! Just upload the Daterange.zip in Kissflow and start using it in your Pages.
